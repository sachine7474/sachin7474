🌐 **DevConnect**  
A developer collaboration platform made with **React** and **Django**, where programmers can discover and join open-source projects. Features include real-time messaging, project feeds, and GitHub OAuth login. Designed to help new contributors connect with experienced devs and contribute effectively. Fully responsive and optimized for both desktop and mobile.

🐳 **Dockerized Blog Engine**  
A simple yet powerful blogging system built using **Flask** and **PostgreSQL**, fully containerized with **Docker**. It uses Docker Compose to manage multi-container setups and allows seamless deployment on any machine. The project focuses on teaching CI/CD and DevOps fundamentals in a hands-on way. 🔒 **SecureVault – Password Manager**  
A secure and easy-to-use password manager developed with **Python and Flask**, storing encrypted passwords in a local SQLite database. Uses **bcrypt** for hashing and **JWT** for user authentication. Emphasizes security best practices and includes a simple UI for managing login credentials. A great blend of backend logic and security implementation.

📡 **IoT Weather Dashboard**  
A live weather monitoring system using **Raspberry Pi**, sensors (DHT11), and a **Flask** web server. Weather data is collected and pushed to the cloud (AWS DynamoDB) and displayed in real time on a sleek web dashboard. It includes historical trends, visualizations, and alerting features. Demonstrates edge-to-cloud communication and data visualization.
